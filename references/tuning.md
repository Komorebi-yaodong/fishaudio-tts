## 1. 模型怎么选

| 模型 | 什么时候用 |
|---|---|
| `s2.1-pro-free` | **默认起点**。测试、原型、开发、小体量 |
| `s2.1-pro` | 上生产。质量/延迟/吞吐都优于 S2-Pro |
| `drama-3` | 需要逐词控制、行内切语言、导演式指令、整场多说话人对话 |
| `s2-pro` | 上一代，仍支持多说话人 + 自然语言表达 |

**免费模型不是残废模型**：同权重，只是没有首音时间（TTFA）和 DPA 保障。

## 2. 生成参数

| 参数 | 取值 | 建议 |
|---|---|---|
| `format` | `mp3`(默认) / `wav` / `pcm` / `opus` | 成品用 `wav`+44100；电话/低延迟用 `pcm`；流播用 `opus` |
| `mp3_bitrate` | 64 / 128 / 192 | 发布级 192，预览 64 |
| `sample_rate` | 如 44100 | 只对 `wav` 有意义 |
| `latency` | `balanced`(默认, ~300ms 首音) / `normal` | **质量优先一律 `normal`** |
| `chunk_length` | 100–300，默认 200 | 小值出音快；**长文本调大更稳更省** |
| `speed` | 0.5–2.0 | 别靠它修节奏，先改脚本停顿 |
| `temperature` | 默认 0.7 | 越低越确定、越"平" |
| `top_p` | 默认 0.7 | 一般不动 |
| `repetition_penalty` | 默认 1.2 | **>1.0 抑制重复音**，卡带式结巴就调它 |
| `max_new_tokens` | 默认 1024 | 限制每 chunk 音频长度 |
| `normalize` | 默认 true | 展开数字/日期/单位。关掉会降低数字、URL 的读法稳定性 |
| `language` | BCP-47，如 `zh-CN` | **只影响规范化与时间戳，不改音色/口音** |

### language 的坑

- 填错**不会毁音色**，只会让 `$300`、`0.9%`、日期读错。
- 支持 15 类规则：en / zh-CN / zh-TW / ja / ko / es-ES / es-MX / fr / de / it / pt-BR / ru / ar / tr / tl。
- `zh-HK`、`yue`、`pt-PT`、`es-419`、`es-US` 目前**跳过规范化**（不报错）。
- **中英混排文本请留空**，让模型按 chunk 自动检测。
- 超过 35 字符或含非法字符 → HTTP 400。

## 3. 三个档位

本 skill 的 `--preset`：

| preset | latency | chunk_length | mp3_bitrate | 用于 |
|---|---|---|---|---|
| `quality`（默认） | `normal` | 200 | 192 | 旁白、有声书、广告成品 |
| `balanced` | `balanced` | 200 | 128 | 一般交付 |
| `fast` | `balanced` | 150 | 128 | 语音助手、实时回复 |

## 4. 音色克隆：素材决定上限

**做不出好效果，八成输在素材。**

硬性要求：

- 每段 **≥10 秒**；**1–2 分钟清晰单人语音**明显提升还原度
- 格式 `.wav` / `.mp3` / `.m4a` / `.opus`，**单声道、单人、干净**
- 禁止：背景音乐、混响、多人重叠、音量忽大忽小

推荐录法：

- **2–3 段，每段 15–20 秒**，连成一个完整段落
- 环境优先级：有窗帘地毯的卧室 > 停着的车内 > 安静办公室 > 任何有软家具的房间
- 避开：开着的窗、空调/风扇/冰箱、他人说话、电视音乐
- 麦克风距嘴约"一个手掌宽"，正常音量，句间留 ~0.5 秒

两个开关：

- `enhance_audio_quality`（**默认开**）：训练前降噪 + 电平归一化。素材脏就开着；**已录音棚级则关掉**，避免二次处理。
- **多段 + 带 `texts` 转写**：覆盖更大音域，同时提升发音准确度。

模型状态：`created → trained / failed`。`train_mode="fast"`（默认）下通常立刻 `trained`。生成报 `reference_id` 无效时，先重新拉一次模型确认 state。

合规：只克隆自己的、或有书面授权的声音。不得使用网上来源或名人声音。

## 5. 排错表

| 症状 | 根因 | 处方 |
|---|---|---|
| 声音像机器人 | 素材短、说话不自然 | 素材拉到 30–60 秒，加停顿、放慢 |
| 不像目标人 | 素材有第二人/背景音 | 确认单人、无 BGM/电视 |
| 音质发闷 | 录音环境差 | 换安静房间、靠近麦克风、换设备 |
| 情绪没生效 | 括号用错 / 位置太远 | 用 `[方括号]`，cue 贴句首 |
| 声音不自然 | 情绪太密 | 拉开间隔、降强度、换音色试、音效后补文字 |
| 卡带式重复 | 采样参数 | `repetition_penalty` → 1.2 |
| 名字/术语读错 | 默认读音不对 | 音素标签，或发音词典 |
| 用了 drama-3 没效果 | `model` 头拼错 | 精确拼写，否则静默回落 `s2.1-pro` |
| 发音词典没生效 | 版本 ID 写错 | 必须用复制出的 Version ID，不能写 `latest` / `V1` |
| 数字/金额读错 | `language` 缺失或错 | 显式给 `zh-CN` / `en`；混排则留空 |
| 返回 429 | 并发超限（无 `Retry-After`） | 指数退避，或提高充值档位 |

## 6. 限制

并发档位（按累计充值，与计费无关，只决定能同时跑几个请求）：

| 档位 | 门槛 | 并发 |
|---|---|---|
| Starter | < $100 | 5 |
| Elevated | ≥ $100 | 15 |
| High Volume | ≥ $1,000 | 50 |

**充值到门槛即刻解锁**，不用先花完。

其他限制：

- 单次请求的文本长度受模型 `max_new_tokens` 影响；超长脚本拆段合成再拼接更稳。
- 发音词典：每请求 ≤3 个，每词典 ≤5000 条规则。
- `language` 标签超过 35 字符或含非法字符 → HTTP 400。
